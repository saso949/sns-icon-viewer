# SNS Icon Viewer (SNSアイコン見え方・識別性チェッカー)

SNS用に検討している複数のアイコン候補画像をアップロードし、**実際のSNS画面（X / Instagram / Discord / LINE / YouTube）や極小サイズに縮小されたときの識別性・視認性**を比較検証できる静的Webアプリケーションです。

🌐 **公開URL (GitHub Pages)**: `https://saso949.github.io/sns-icon-viewer/`

## 主な機能

1. **複数アイコン候補の一括アップロード＆比較**
   - ドラッグ＆ドロップ、ファイル選択、またはクリップボード貼り付け（`Ctrl + V`）で複数枚のアイコン候補をまとめて追加可能（すべてブラウザ内で処理され、外部サーバーへは送信されません）。
2. **3つの比較モード**
   - **タイムライン混在比較モード**: アップロードしたすべての候補アイコンを同じタイムライン内に並べて埋め込み、どれが一番パッと目に入るかを直感的に比較できます。
   - **単一アイコン集中確認モード**: 選択した1つの候補（数字キー `1`〜`9` でも瞬時に切替可能）を全SNS枠に適用して確認できます。
   - **サイズ・背景マトリクス表**: 全候補 × ピクセルサイズ（`128px` / `56px` / `40px` / `32px` / `24px` / `16px`）× 背景色（白 / 紺 / 黒）× 角丸形状を一覧表で横並び比較できます。
3. **5大SNSモックアップ表示**
   - **X (旧Twitter)**: プロフィールヘッダー重なり（`72px`）、タイムライン投稿（`40px`）、スレッド返信（`32px`）、引用ポスト内極小表示（`20px`）
   - **Instagram**: 虹色グラデーションリング付きストーリーズ（`56px`）、フィード投稿（`32px`）、コメント欄（`28px` / `24px`）
   - **Discord**: 右下にオンラインステータスドットが切り欠き表示されるチャット（`40px`）＆メンバー一覧（`32px`）
   - **LINE**: トーク一覧（`48px`）＆青背景トークルーム吹き出し横（`36px`）
   - **YouTube**: チャンネルバー（`36px`）＆コメント・返信（`40px` / `24px`）
4. **識別性・背景溶け込み診断＆テストフィルタ**
   - **ライト / ディム(紺) / ダーク(黒)** の3種類のSNS背景テーマをワンクリック切替
   - 白背景アイコンのライトモード同化・黒背景アイコンのダークモード同化・明度コントラストを自動判定してバッジ表示
   - **白黒(明度確認)**・**ぼかし(シルエット確認)**・**遠目表示(75%縮小)** フィルタ搭載
5. **位置・拡大率調整＆切り抜きPNG保存**
   - 各候補ごとに拡大率（100%〜300%）や上下左右位置をドラッグまたはスライダーで微調整でき、調整後の `512×512` PNG画像としてダウンロード可能。
